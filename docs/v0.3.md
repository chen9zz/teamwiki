# v0.3：层级导入、分页和真实浏览器回归

## 层级规则

`Handbook/Guides/start.md` 会创建空白目录页 `Handbook`、其子目录页 `Guides`，再创建子文档 `start`。目录是可编辑的普通 Page；同名 Markdown 和目录使用不同稳定 ID，不会合并已有空间页面。ZIP 条目顺序不影响父子关系。空目录不生成页面。

文件继续以规范相对路径作为导入项目键，目录使用保留前缀 `dir:`。身份同时受 ImportJob 和 Workspace 范围约束；重复消费同一任务不会重复创建目录、文件或修订。所有页面、链接、修订、审计和任务完成状态同事务提交，失败全部回滚。不同任务再次导入同一目录会创建独立的目录树。

限制：8 MiB 上传、2 MiB 单文件、16 MiB 展开、200 Markdown、200 生成目录、20 层目录、400 总页；压缩比最多100，ZIP条目最多400。拒绝危险路径、符号链接、加密、非UTF-8、重复文件路径及仅大小写不同的目录身份。目录标题截断后为空会在排队前返回422。`total/processed/result` 仅统计或返回 Markdown 文件；进度仍是原子可见的0→N，不提供部分完成导入。

## 分页接口与界面

| API | 行为 |
| --- | --- |
| `GET /api/workspaces/{wid}/page-tree` | 无parent_id仅根；带parent_id加载该父页的直接子页；校验父页属于当前空间且未删除 |
| `GET /api/workspaces/{wid}/page-summaries` | 平铺元数据批次，用于首页和父选择器；不读取正文 |
| `GET /api/workspaces/{wid}/pages/{pid}/revisions` | 保留旧数组接口，支持limit/offset；前端加载更早版本 |
| `GET /api/workspaces/{wid}/pages/{pid}/revisions/{version}/links` | 只读解析所选历史正文；目标仅查询当前空间id/title/deleted_at；不写关系索引 |

树和摘要返回 `{items,limit,offset,has_more}`；默认50条、最多200条，按title/id排序。`has_children` 查询只读元数据。新增 `0002_page_tree_order` 的 `(workspace_id,parent_id,deleted_at,title,id)` 索引支持兄弟分页和子节点存在性检查，无新增业务字段。已有 `(page_id,version)` 唯一索引支持历史查询。

前端按展开请求子树，根、兄弟、父页正文内子文档、历史、搜索均以50条分批加载。首页明确显示已加载数量。父选择器保留尚未加载的当前父节点，后端继续验证移动权限与防环。新建、移动、删除、恢复和导入按空间前缀失效查询。管理详情请求在切空间或切换弹窗意图时取消，迟到结果不会覆盖新输入。

历史标题链接按当前空间解析；原关系快照没有保存在 PageRevision 中，界面明确标注。显式ID仍按当前删除状态解析，重名为ambiguous，缺失为unresolved。历史预览不会改写已发布正文的链接索引。

## 真实浏览器

Playwright1.64.1 Chromium 使用已编译、由Nginx提供的前端和真实API/PostgreSQL/Redis/Celery/Beat，没有路由拦截或响应mock，也没有Vite服务。每个worker创建独立合成账户，每项测试创建独立空间；一个worker，无自动重试，遵守认证限流。

六项覆盖：UI登录/CodeMirror编辑/保存并回读；两个独立浏览器会话同版本竞争及409草稿恢复；Viewer只读和强制PATCH403；ZIP从UI上传到真实Worker完成并展开层级；103页目录根/兄弟跨50以及直接打开父页正文子文档分页；52条历史跨50并点击旧版本链接。

运行方式见 [E2E说明](../frontend/e2e/README.md)。CI的containers任务在完整Compose就绪后执行相同浏览器套件；失败时保存trace、截图和容器日志。Git和Docker上下文排除浏览器产物、认证状态与.env。

## 现有边界

- 采用offset分页，稳定排序不等于并发结构变更中的快照；刷新会重新加载已请求批次。历史最后一批恰好50条时，需要额外空批确认结束。
- 回收站、审计和全量图谱没有在本轮改为无限列表；历史链接解析仍扫描当前空间的目标元数据，不查询其他页面正文。
- ZIP导出仍是同步、有限额的Markdown导出；不保留完整数据库或导入目录往返格式。导入进度仍原子可见。
- 本轮没有新增性能基准或生产容量结论；v0.2短测结果保持其原始条件与限制。
